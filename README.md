## 📋 Description

Ce projet consiste en une **application de gestion** permettant d’accéder à une base de données et d’assurer la **gestion complète de quatre casernes de pompiers**, incluant :  
- Le **personnel**  
- Le **matériel**  
- Les **missions effectuées**

<br>

## 🚀 Comment lancer le programme

Pour l’instant, le programme doit être ouvert via **Visual Studio** et lancé directement depuis l’interface graphique de l’IDE.

<br>

## 🛠️ Technologies utilisées

- **C#** — Langage de programmation orienté objet utilisé pour le développement de l’application  
- **WinForms** — Framework .NET pour la création d’interfaces graphiques Windows  
- **SQLite** — Système de gestion de base de données relationnelle embarqué  
- **Visual Studio** — Environnement de développement intégré (IDE) utilisé pour coder et exécuter le projet
